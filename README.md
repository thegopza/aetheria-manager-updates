# PmheeAether Manager updates

Public automatic-update channel. Generated from reviewed, committed Manager runtime files; do not edit this checkout as development source.

This is not an installer package. Existing Managers receive the transition update from the original repository while it is temporarily public. Offline or outdated clients must obtain the installation ZIP from the owner before that repository becomes private. Private bot source/payloads and customer state are not distributed here. Private bots use the owner API and signed local cache.
